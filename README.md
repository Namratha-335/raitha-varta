# 🌾 Raitha Varta

Raitha Varta is an Android application developed using Kotlin and Android Studio to help farmers receive simple agricultural guidance.

## Features
- 🌦 Weather Advisory
- 📄 PDF Advisory
- 🤖 AI Kannada Tips
- 🌱 Crop Tips
- 👨‍🌾 Farmer Registration
- 📸 Expert Suggestion
- 🏆 Success Stories

## Technologies Used
- Kotlin
- Android Studio
- RecyclerView
- XML UI Design

## Objective
The app converts long agricultural advisories into short and understandable farming tips for farmers.
